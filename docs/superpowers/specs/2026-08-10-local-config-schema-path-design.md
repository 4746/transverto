# Default Local `.ctv.config.json` Schema Path Design

## Goal

Make every configuration generated by `ctv init` reference the JSON Schema shipped in the project's locally installed Transverto package.

## Generated value

`ctv init` always emits this exact first property:

```json
"$schema": "./node_modules/@cli107/transverto/schema/ctv.config.schema.json"
```

Rename `CTV_CONFIG_SCHEMA_URL` to `CTV_CONFIG_SCHEMA_PATH` and set it to this value. All generated configuration and fixture assertions consume that constant.

## Schema structure

Replace the current `const` under `properties.$schema` with `type: "string"`. Do not add `const`, `enum`, `oneOf`, `pattern`, URI format, or path restrictions. Users may manually replace the generated value; validating or supporting those custom references is outside Transverto's responsibility.

The schema's own `$id` remains the official public URL because it identifies the published schema artifact and does not control the generated reference value.

## Generated configuration and compatibility

Existing configuration files with the public URL or another string remain valid when their chosen schema can be loaded. New projects require `@cli107/transverto` to be installed locally at the standard npm package path for editor discovery to work. A global-only installation does not provide the referenced project-relative file.

## Documentation and verification

- Update init, fixture, and schema identity tests to assert the exact generated local path.
- Verify that the schema only requires `$schema` to be a string and does not police custom string values.
- Update the README example to use `./node_modules/@cli107/transverto/schema/ctv.config.schema.json`.
- Run focused schema tests, the full test/lint suite, build, and npm pack dry-run verification.
